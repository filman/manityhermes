# Manity Hermes

Showcase site for the Manity Health Platform submission to the **TRISH HERMES 2023** Request for Proposals (Application `HERMES2301-0000000017`).

The Manity Health Platform is an open, FHIR-native EHR and medical data orchestration system purpose-built for dynamic operating environments — space, military, deep-sea — where connectivity is intermittent and the cost of stale data is human.

## What's here

A static site with no build step:

- `index.html` — content
- `styles.css` — styling
- `script.js` — starfield background + smooth scroll

## Local preview

Open `index.html` directly in a browser, or:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## Deploy

The repo works as-is on **GitHub Pages**, **Netlify**, **Vercel**, **Cloudflare Pages**, or any static host. For GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
